CSS-stilar jag har lärt mig

  • display - bestämmer hur ett element visas på sidan.
  • color - ändrar färgen på texten
  • background-color - ändrar bakgrundsfärgen
  • font-size - ändrar storleken på texten
  • font-weight - bestämmer hur tjock texten ska vara.
  • border - lägger till en ram runt ett element.
  • border-radius - gör hörnen på ett element rundare.
  • padding - skapar utrymme innanför ett elements kant
  • margin - skapar utrymme utanför ett element.
  • gap - bestämmer avståndet mellan element
